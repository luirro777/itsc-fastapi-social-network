# Construyendo una red social rudimentaria con FastAPI

## Descargar:

```
git clone https://github.com/luirro777/itsc-fastapi-social-network
```
## Inicializar uv (esto debe hacerse 1 sola vez)

```
cd itsc-fastapi-social-network/
uv sync

```

## Correr la API

En la medida que vayamos avanzando con las clases, la ruta
irá cambiando. Al 22-10-2026 la misma es:

```
uv run fastapi dev clase2/esqueleto/main.py
```



En el código fuente encontrarán la consigna
